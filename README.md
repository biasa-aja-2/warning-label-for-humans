The funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer:

> WARNING: This human will spend 40 minutes choosing a film, then fall asleep ten minutes into the opening credits.

One read, one idea, the turn in the last few words — the long browse, then asleep before the film even starts. Pure-stdlib Python writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
